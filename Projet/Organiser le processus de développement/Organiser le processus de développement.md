# Organiser le processus de développement

| **Étape** | **Objectif et livrable** |
|---|---|
| **Cadrer** | Comprendre le besoin : ajouter une catégorie et gérer les différentes opérations comme la suppression, la modification et l’affichage. |
| **Concevoir** | Définir la structure : créer la table `category` (id, name, color…), concevoir la structure de l’API et déterminer les éléments du formulaire. |
| **Développer** | Créer le formulaire HTML avec prévalidation, le tableau d’affichage des catégories, les opérations CRUD de l’API (**POST, PUT, DELETE, GET**) et la table SQL. |
| **Tester** | Vérifier que toutes les fonctionnalités fonctionnent correctement : affichage, ajout, suppression et modification. Documenter les erreurs rencontrées ou indiquer **0 erreur**. |
| **Valider** | Vérifier que les fonctionnalités répondent aux attentes et qu’aucune modification n’a été effectuée en dehors du périmètre défini. |
